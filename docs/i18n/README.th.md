# YouGlish Downloader

### 🎧 ฟังมัน ตัดมัน เก็บช่วงเวลานั้นไว้

**ค้นหาคำหรือวลีใดก็ได้ในเสียงพูดจริง แล้วบันทึกคลิปที่ตรงกันทุกตำแหน่ง** YouGlish Downloader ผสานการค้นหาการออกเสียงของ YouGlish เข้ากับเครื่องมือตัดคลิปบนเดสก์ท็อป คุณค้นวลีในภาษาและสำเนียงที่เลือกได้ ฟังว่าคนพูดจริงในบริบทอย่างไร และดาวน์โหลดเฉพาะช่วงเวลาที่ต้องการ

- 🎓 **ผู้เรียนภาษา:** ฟังคนจริงพูดในบทสนทนาจริง ไม่ใช่แค่การอัดเสียงจากหนังสือเรียน
- 👩‍🏫 **ครู:** สร้างคลิปตัวอย่างที่เปิดเล่นได้ทันทีและเหมาะกับบทเรียนของคุณ
- 🔎 **ทุกคนที่กำลังหาวลี:** ค้นหาว่าวลีนั้นถูกพูดที่ไหนบน YouTube ในภาษาที่คุณเลือก แล้วเก็บเฉพาะช่วงนั้น

ดาวน์โหลดเฉพาะเนื้อหาที่คุณเป็นเจ้าของหรือได้รับอนุญาตให้ดาวน์โหลดได้

![แอป YouGlish Downloader: ค้นหาวลี ตัดคลิป และเพิ่มลงในคิวดาวน์โหลด](../images/app-preview.webp)

เวอร์ชันเดสก์ท็อปของ TubeCutter สำหรับค้นหาตัวอย่างการพูดด้วยตนเองผ่านวิดเจ็ต YouGlish อย่างเป็นทางการ โปรเจกต์นี้มีตัวระบุแอปและการตั้งค่าเป็นของตัวเอง

## ดาวน์โหลด

- **Windows:** [ดาวน์โหลดรุ่นล่าสุด](https://github.com/MolecularDust/Youglish-Downloader/releases/latest) เลือกการติดตั้งแบบปกติหรือสำเนาแบบพกพาได้
- **macOS (Apple silicon):** [ดาวน์โหลดรุ่น macOS](https://github.com/MolecularDust/Youglish-Downloader/releases/tag/v0.3.0-macos)

## ตั้งค่าการเข้าถึง YouTube

1. เปิดแอปแล้วคลิก **Account & Settings**
2. ภายใต้ **YouGlish playback account** คลิก **1. Sign in to Google ↗** แล้วคลิก **2. Connect YouTube ↗** และเลือกช่องของคุณเมื่อมีการขอ ปิดหน้าต่างบัญชีเมื่อเสร็จ **Check playback ↗** เล่นวิดีโอตัวอย่างเพื่อยืนยันว่าใช้งานได้
3. ภายใต้ **Subtitle and download authentication** เลือก **App’s YouTube session** สำหรับ **Download authentication**

พร้อมใช้ YouGlish Downloader แล้ว

หากต้องการใช้เบราว์เซอร์ที่ลงชื่อเข้าใช้อยู่แล้ว ให้เลือกเบราว์เซอร์นั้นภายใต้ **Download authentication** บน Windows ให้ปิดเบราว์เซอร์นั้นก่อนค้นหา เพราะเบราว์เซอร์ที่ใช้ Chromium จะล็อกไฟล์คุกกี้ขณะทำงาน จึงควรใช้เซสชันของแอปเองซึ่งเชื่อถือได้มากกว่า ใช้เฉพาะบัญชีของคุณ อย่านำเข้าหรือแชร์คุกกี้ของผู้อื่น

คุณจะคงค่า **Anonymous** ไว้ก็ได้ แต่การตรวจสอบต่อต้านบอตของ YouTube เข้มงวดกว่าสำหรับการเข้าถึงแบบไม่ระบุตัวตน และวิดีโอบางรายการอาจใช้งานไม่ได้

## การใช้งาน

เปิด `src-tauri/target/debug/bundle/macos/YouGlish Downloader.app` หลังจากสร้างแอปแล้ว หรือรัน `npm run desktop` เพื่อพัฒนา

1. ป้อนวลีที่ต้องการค้นหา ภาษา และสำเนียงเพิ่มเติม (ถ้าต้องการ) แล้วค้นหา ค่าเริ่มต้นคือภาษาอังกฤษทุกสำเนียง
2. เรียกดูและฟังใน YouGlish คำบรรยายของตัวอย่างที่เลือกจะเติมลงใน File Name และจะคงอยู่ระหว่างการเล่น
3. แก้ไข File Name ให้เป็นวลีจากซับไตเติลของวิดีโอ คลิก **Look Up** หรือกด Enter การแก้ไขหรือออกจากช่องจะไม่เริ่มการค้นหา ปุ่มจะแสดงตัวหมุนจนกว่าการจับคู่จะสำเร็จหรือล้มเหลว ข้อความนี้ยังเป็นชื่อไฟล์ที่บันทึกด้วย (คอนเทนเนอร์จะเพิ่มนามสกุลให้)
4. ซับไตเติลที่มีให้จะได้รับความสำคัญก่อน ใช้เฉพาะคำบรรยายอัตโนมัติต้นฉบับที่ยังไม่ได้แปลเป็นทางเลือกสำรอง การจับคู่จะไม่สนใจตัวพิมพ์ใหญ่-เล็ก เครื่องหมายวรรคตอน และรูปแบบของอพอสทรอฟี จะครอบคลุมคิวที่อยู่ติดกันและตัดข้อความวิ่งที่ซ้อนทับออก
5. เมื่อเลือกวิดีโอ In/Out จะตั้งเป็นศูนย์และความยาวเต็มของวิดีโอก่อน การจับคู่หนึ่งรายการจะตั้ง In/Out ไปที่ขอบของส่วนซับไตเติลที่มีคำนั้น โดยไม่เพิ่มช่องว่างรอบ หากมีหลายรายการต้องเลือกหนึ่งตำแหน่ง หากไม่มีการจับคู่ เวลาเดิมจะไม่เปลี่ยน ค่านี้เป็นขอบของส่วนซับไตเติล ไม่ใช่การจัดแนวเสียงระดับคำ
6. ใช้ลูกศรเล็กเพื่อเปลี่ยนขอบด้านใดด้านหนึ่งหรือความยาวทีละหนึ่งวินาทีพอดี **Reset** จะคืนค่าวิดีโอทั้งหมดและล้างข้อมูลที่ไม่ถูกต้องและข้อผิดพลาดการตรวจสอบ ขอบที่ไม่ถูกต้องจะถูกปฏิเสธ คุณยังพิมพ์เวลาโดยตรงได้ พิมพ์ Length ได้ (ความยาวคลิปที่มีช่องว่างรอบซึ่งแสดงในช่อง โดย Out จะปรับตามให้) ลากไทม์ไลน์ หรือใช้ **Preview selection** ได้
7. **Preview selection** จะสลับพื้นที่วิดเจ็ตเป็นเครื่องเล่น YouTube ที่ฝังไว้ชั่วคราวเพื่อการเลื่อนตำแหน่งที่แม่นยำ **Back to YouGlish results** กลับไปยังการเรียกดู **Set In** และ **Set Out** ต้องใช้การพรีวิวนี้ เพราะ YouGlish ไม่เปิดเผยตำแหน่งการเล่นสัมบูรณ์ที่มีเอกสารรองรับ
8. การตั้งค่าการดาวน์โหลดจะถูกพับไว้ในตอนแรก ความละเอียดเริ่มต้นคือความละเอียดสูงสุดที่มีไม่เกิน 1080p เมื่อดาวน์โหลด คำขอ 1080p จะยอมรับความละเอียดต้นทางที่ต่ำกว่าที่มีด้วย ความละเอียดอื่นที่เลือกไว้จะยังคงแม่นยำ
9. เลือกโฟลเดอร์ปลายทางและเพิ่มส่วนที่เลือกลงในคิวดาวน์โหลดแบบลำดับ คงไว้ซึ่ง **Precise Cut** การหยุดชั่วคราว/เล่นต่อ/ยกเลิก/ลองใหม่ การฝังซับไตเติล และการแสดงใน Finder

**Account & Settings** เป็นแบบไม่ระบุตัวตนโดยค่าเริ่มต้น เบราว์เซอร์ที่รองรับและติดตั้งอยู่จะถูกตรวจพบในตำแหน่งแอปปกติของ macOS เมื่อเลือกหนึ่งรายการ yt-dlp จะอ่านที่เก็บคุกกี้ในเครื่องของเบราว์เซอร์นั้นเพื่อซับไตเติลและการดาวน์โหลดได้ คุกกี้จะไม่ถูกฉีดเข้า YouGlish และไม่ถูกเก็บไว้ในการตั้งค่า วิดเจ็ตใช้เซสชัน WebView ของตัวเอง การตั้งค่าแอปและตัวตนของคิวแยกจาก TubeCutter

## ภาษา

อินเทอร์เฟซของแอปมีให้ใช้ทั้งภาษาอังกฤษและอีก 19 ภาษา ได้แก่ อาหรับ เบงกาลี จีน (ตัวย่อ) ฟิลิปปินส์ ฝรั่งเศส เยอรมัน ฮินดี อินโดนีเซีย อิตาลี ญี่ปุ่น เกาหลี เปอร์เซีย โปรตุเกส (บราซิล) รัสเซีย สเปน เตลูกู ไทย ตุรกี และเวียดนาม โดยค่าเริ่มต้นจะทำตามภาษาของระบบ หากต้องการเลือกภาษาอื่น ให้เปิด **Account & Settings → Language** ซึ่งการเลือกจะมีผลทันทีและจะถูกจดจำไว้ อาหรับและเปอร์เซียจะจัดวางจากขวาไปซ้าย

คำแปลอยู่ใน `src/locales/<code>.json` และข้อความภาษาอังกฤษทำหน้าที่เป็นคีย์ หากต้องการเพิ่มหรือแก้ไขคำแปล โปรดดู[หมายเหตุการแปลภาษา](../LOCALIZATION.md)
