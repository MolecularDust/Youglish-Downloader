# YouGlish Downloader

### 🎧 Слушайте. Вырезайте. Сохраняйте момент.

**Найдите любое слово или фразу в живой речи и сохраните точный фрагмент.** YouGlish Downloader объединяет поиск произношения YouGlish с настольным инструментом для вырезания: ищите фразу на выбранном языке и с выбранным акцентом, слушайте, как её на самом деле произносят люди в контексте, и скачивайте только нужный момент.

- 🎓 **Изучающим языки:** слушайте настоящих людей в настоящих разговорах, а не только записи из учебников.
- 👩‍🏫 **Преподавателям:** создавайте готовые к воспроизведению примеры для урока.
- 🔎 **Всем, кто ищет фразу:** находите, где на YouTube её произносят на нужном языке, и сохраняйте только этот момент.

Скачивайте только материалы, которыми вы владеете или на скачивание которых у вас есть разрешение.

![Приложение YouGlish Downloader: поиск фразы, вырезание фрагмента и добавление в очередь загрузки](../images/app-preview.webp)

Настольная версия TubeCutter для ручного поиска примеров речи с помощью официального виджета YouGlish. У этого проекта свой идентификатор приложения и свои настройки.

## Загрузка

- **Windows:** [Скачать последний выпуск](https://github.com/MolecularDust/Youglish-Downloader/releases/latest). Выберите обычную установку или portable-копию.
- **macOS (Apple silicon):** [Скачать выпуск для macOS](https://github.com/MolecularDust/Youglish-Downloader/releases/tag/v0.3.0-macos).

## Настройте доступ к YouTube

1. Откройте приложение и нажмите **Account & Settings**.
2. В разделе **YouGlish playback account** нажмите **1. Sign in to Google ↗**, затем **2. Connect YouTube ↗** и выберите канал, если это потребуется. Закройте окно аккаунта, когда закончите. **Check playback ↗** воспроизводит пример видео, чтобы проверить работу.
3. В разделе **Subtitle and download authentication** для **Download authentication** выберите **App’s YouTube session**.

Теперь вы можете пользоваться YouGlish Downloader.

Чтобы использовать браузер, в котором вы уже вошли в аккаунт, выберите его в **Download authentication**. В Windows закройте этот браузер перед поиском: браузеры на основе Chromium блокируют файл cookie, пока работают, поэтому собственный сеанс приложения там надёжнее. Используйте только свой аккаунт. Не импортируйте и не передавайте чужие cookie.

Можно оставить **Anonymous**, но проверки YouTube против ботов для анонимного доступа строже, и некоторые видео не будут работать.

## Использование

После сборки откройте `src-tauri/target/debug/bundle/macos/YouGlish Downloader.app` или запустите `npm run desktop` для разработки.

1. Введите поисковую фразу, язык и при необходимости акцент, затем нажмите «Поиск». По умолчанию — английский со всеми акцентами.
2. Просматривайте и слушайте в YouGlish. Подпись выбранного примера заполняет File Name и остаётся там во время воспроизведения.
3. Измените File Name на фразу из субтитров видео. Нажмите **Look Up** или Enter. Редактирование поля или уход из него не запускает поиск. Кнопка показывает индикатор, пока совпадение не будет найдено или не окажется неудачным. Этот текст также становится именем выходного файла (расширение добавит контейнер).
4. Предоставленные субтитры имеют приоритет. В качестве запасного варианта используются только исходные автоматические подписи без перевода. При сопоставлении не учитываются регистр, знаки препинания и стиль апострофа; учитываются соседние фрагменты, а перекрывающийся бегущий текст убирается.
5. При выборе видео значения In/Out сначала устанавливаются в ноль и полную длительность видео. Одно совпадение устанавливает In/Out на границы содержащего его сегмента субтитров, без отступов. Несколько совпадений требуют выбрать одно вхождение. Если совпадений нет, существующие тайминги не меняются. Это границы сегментов субтитров, а не выравнивание звука по словам.
6. Маленькие стрелки меняют любую границу или длительность ровно на одну секунду. **Reset** восстанавливает всё видео и очищает неверный ввод и ошибки проверки. Недопустимые границы отклоняются. Можно также вводить временные метки вручную, вводить Length (длительность фрагмента с отступами, показанная в поле; Out подстраивается под неё), перетаскивать временную шкалу или использовать **Preview selection**.
7. **Preview selection** временно заменяет область виджета встроенным плеером YouTube для точной перемотки. **Back to YouGlish results** возвращает к просмотру. **Set In** и **Set Out** требуют этого предпросмотра, потому что YouGlish не предоставляет задокументированную абсолютную позицию воспроизведения.
8. Настройки загрузки изначально свёрнуты. Разрешение по умолчанию — наивысшее доступное, но не выше 1080p. При загрузке запрос 1080p также допускает доступные более низкие разрешения источника. Другие выбранные разрешения остаются точными.
9. Выберите папку назначения и добавьте выделенный фрагмент в унаследованную последовательную очередь загрузки. Сохраняются **Precise Cut**, пауза/продолжение/отмена/повтор, встраивание субтитров и показ в Finder.

**Account & Settings** по умолчанию анонимны. Поддерживаемые установленные браузеры обнаруживаются в обычных местах приложений macOS. Если выбрать один из них, yt-dlp может читать его локальное хранилище cookie для субтитров и загрузок; cookie не внедряются в YouGlish и не сохраняются в настройках. Виджет использует собственный сеанс WebView. Настройки приложения и идентификация очереди отделены от TubeCutter.

## Язык

Интерфейс приложения доступен на английском и ещё на 19 языках: арабском, бенгальском, китайском (упрощённом), филиппинском, французском, немецком, хинди, индонезийском, итальянском, японском, корейском, персидском, португальском (Бразилия), русском, испанском, телугу, тайском, турецком и вьетнамском. По умолчанию язык соответствует языку системы. Чтобы выбрать другой, откройте **Account & Settings → Language**; выбор применяется сразу и запоминается. Арабский и персидский выводятся справа налево.

Переводы находятся в `src/locales/<code>.json`, а ключом служит английский текст. Чтобы добавить или исправить перевод, см. [заметки о локализации](../LOCALIZATION.md).
